# Expense Tracker System

## Description
A simple expense management application developed using Java Swing.

## Features
- Add expenses
- View expense records
- Delete expenses
- Calculate total expenses
- Track monthly budget and remaining balance
- Save expense records in a CSV file

## Technologies Used
- Java
- Java Swing
- File Handling
- CSV Storage

## How to Run
1. Install JDK 11 or later.
2. Download `ExpenseTracker.java`.
3. Open a terminal in the folder containing the file.
4. Compile using `javac ExpenseTracker.java`.
5. Run using `java ExpenseTracker`.

## Project Status
Basic implementation; testing and further improvements are in progress.
